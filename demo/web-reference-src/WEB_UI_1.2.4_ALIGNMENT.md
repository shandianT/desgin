## 设计展示需要覆盖的变化

| 区域 | 1.2.2 展示 | 1.2.4 对齐结果 |
|---|---|---|
| 跟进建议/待办 | 建议子组件和旧 Sheet 展示 | 采用建议操作后可进入任务确认，拒绝后刷新状态；保持权限检查和草稿回读 |
| 桌面弹窗 | 多处底部 Sheet | 人员、客户、商机选择/简短编辑使用居中 Modal；建议、协作、指标明细使用右侧 Drawer；原生确认框焦点交接保留 |
| 客户/商机选择 | 名称排序 | 跟进入口显式使用 `order=recent_follow_up`；无正式跟进记录后置，同名按名称和 ID 稳定排序 |
| 协同人 | 可选列表未排除当前人 | 协同候选排除当前跟进人，保留原授权范围 |
| 加载/恢复 | 主要展示普通加载与错误 | 重型读取显示等待；失败时保留已显示数据、草稿和筛选条件，提供重试/恢复状态 |

## 来源与可重建边界

本次只登记固定源码、差异和待导入快照清单；没有伪造 1.2.4 压缩包或校验值。完整 Web 产品仍需产品仓库的构建脚本、共享源码、依赖和合成数据适配，设计仓库的 `/web/` 与 `department-ui/` 不能独立构建完整产品。导入 b9a32ef2 导出包后，应补齐 dist/UI 源码文件数、树校验值和逐文件校验，并运行 `node tools/verify-web-snapshot.mjs`、`node tools/check.mjs` 及页面交互回归。

## 规范边界

保留 26 条已确认 Web 规则、公共组件和设计变量。产品覆盖色 `#3370FF` 继续只属于产品 UI 覆盖层；部门规范色 `#2863CD` 不变。本记录不把产品展示变化升级为部门规范变更。

- 真实业务验收：需产品仓库、真实身份/权限、接口和数据库条件另行验证。
