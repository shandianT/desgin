# 组件选型指南：什么时候用哪个

页面上同一件事常常有两三个组件都能做：上游 Ant Design 6 的原生控件，和部门 `@shandiant/ui-react` 里包了一层的 Sb 组件。原则只有一条：**上游控件负责通用交互，Sb 组件负责部门口径**（文案、缺失值、四态、变量、业务状态）。凡是页面要表达业务含义的地方，用 Sb 组件；只是一个通用输入或展示，用上游。

每一行：场景一句、选哪个、为什么。上游控件的状态和样子在组件库目录页「基础控件」一节，Sb 组件在目录页各自的卡片，用法点卡片右上角「用法」。

## 一张表

| 场景 | 选哪个 | 为什么 |
|---|---|---|
| 表单里从固定几项里选一个，选项不带数量 | Select（antd） | 通用选择，SbProvider 已把主题接好，不需要再包一层 |
| 表单里选阶段、类型，选项要带灰小字数量，或统一 options 结构 | SbSelect | 统一 `options[{value,label,count}]`，数量灰小字，缺省不带清除 |
| 列表页筛选，标签在框内左侧，没选显示「全部」 | SbLabeledSelect | 筛选语义：值清空回「全部」，多个并排对齐；选项少于 6 个改用筛选片 |
| 选客户、选人、关联商机，选项要按关键词到服务端找 | SbSearchSelect | 远程搜索、防抖、三种下拉提示（输入关键词、正在搜索、没有匹配）已做好 |
| 列表顶部一排筛选片加结果数、清除 | SbFilterBar | 标题带范围、已选数、结果数、清除紧邻结果区，C-04 的要求一次到位 |
| 按区域到地盘这种有层级的选择 | Cascader（antd） | 层级选择是通用交互，没有部门口径，直接用 |
| 象限名、客户层级、部门这种分类标识 | Tag（antd） | 只是归类，不带好坏；不要用 Tag 的颜色表达状态 |
| 向好、需关注、转差、待评估、未登记这类业务状态 | SbStatusTag | 红黄绿灰必带文字，可带依据，颜色只走变量（B-01） |
| 只演示或临时看一眼数据的表格 | Table（antd） | 原生能力够用，没有四态与操作列的要求 |
| 客户、商机、任务、成员这些业务列表表格 | SbTable | 操作列固定右侧、四态接 SbStatePanel、分页接 SbPagination、行高两档；排序与勾选从 columns 的 sorter 与 rowSelection 透传 |
| 表单里的日期、区间，要今天／本周／本季快捷项，值是字符串 | SbDatePicker | 中文文案、快捷项、对外只收发 `YYYY-MM-DD`，页面不用碰 dayjs |
| 需要 antd DatePicker 的原生能力，如时间选择、周选择 | DatePicker（antd） | SbDatePicker 只包了日期与区间，其它模式直接用上游 |
| 拜访口述、任务说明、拒绝意见这类长文本 | SbTextarea | 带字数、上限 500、高度随内容 3～8 行，口径统一 |
| 一两行的备注，没有字数要求 | Input.TextArea（antd） | 通用输入，不需要口径 |
| 金额、台数这类数字 | SbAmountInput | 单位默认万元、千分位、只收非负、空是 null 不是 0 |
| 数量步进、百分比这类普通数字 | InputNumber（antd） | 没有金额口径 |
| 看板、总览的本人／团队、本年／历年二到五项切换 | SbSegmented | 统一 options、默认 small；多于 5 项换 SbTabs 或下拉 |
| 需要图标项或自定义渲染的分段 | Segmented（antd） | SbSegmented 只收文字项 |
| 待处理、已完成、全部这类页签，要显示数量 | SbTabs | 数量小号灰字，超过 99 显示 99+ |
| 详情页拜访、商机、合同这类内容页签，不带数量 | Tabs（antd） | 通用页签 |
| 确认、二次确认这种打断当前操作的对话 | Modal（antd） | 通用对话框，Esc 可关、焦点回按钮 |
| 电脑端看详情、编辑表单，不离开列表 | Drawer（antd） | 右侧抽屉是电脑端惯例 |
| 手机宽度下的选择、确认、详情浮层 | SbSheet | 底部弹层带标题、关闭、取消，不替代页面级返回（C-07、X-03） |
| 按钮提交中、局部刷新 | Spin（antd） | 局部转圈，不占整块 |
| 详情页、总览首屏的加载占位 | Skeleton（antd） | 占位形状跟内容走 |
| 列表、表格、图表整块的加载中、空、失败、无权限 | SbStatePanel | 四态一个组件，文案统一，重试不清筛选，无权限不露对象名（C-06、P-03） |
| 一个数字加说明，缺失显示未登记 | SbMetricTile | 单个指标，不显示 0 |
| 几个指标横排，右侧周期切换与口径 | SbMetricStrip | 指标条一行式，默认 flat 靠留白分组（14 章） |
| 看板上的指标卡，数字大、带升降变化 | SbKpiCard | 数字 32、单位小一号、升绿降红只在有好坏时用（12 章） |
| 客户详情、商机详情的跟进历史、业务动态 | SbTimeline | 节点色只由 tone 决定（good、watch、bad、pending、neutral），时间、标题、说明三行统一，末尾「进行中」占位；只是几步流程展示用 antd Steps 或 Timeline 原生 |
| 拜访附件、合同扫描件、任务交付物 | SbUpload | 文件结构统一、超类型／大小／数量就地说明不弹 toast、说明按 accept 与 maxSize 生成；头像裁剪这类特殊上传用 antd Upload 原生 |
| 归档成功、提交失败、需补充这类整页反馈 | SbResult | 图标色走语义变量，一个主按钮一个次按钮，extra 放数字；404、403 页面用 antd Result 原生的 404／403 状态 |
| 侧栏账号、记录人、执行人、成员列表的头像 | SbAvatar | 姓名后两字、三档 24／32／40、底色档默认主色淡底；只是放一个图标占位用 antd Avatar 原生 |

## 三条判断顺序

1. 页面要表达业务含义（状态、缺失、口径、四态）就用 Sb 组件，没有就用上游。
2. 两个 Sb 组件都像的，看场景词：表单用 SbSelect，筛选用 SbLabeledSelect；单个数字用 SbMetricTile，一排用 SbMetricStrip，看板大数字用 SbKpiCard。
3. 都没有的，先用上游拼，在交回说明里写「建议新增组件」，不要在页面里造一个只用一次的。
