# 16｜飞书参照与小程序体验

## 1｜依据与边界

- **数值依据**：npm `@semi-bot/semi-theme-feishu` 1.0.0（Semi DSM 生成的飞书主题）里的 `_palette.scss`、`global.scss`、`variables.scss`。这是本环境能拿到的唯一飞书官方来源的数值；飞书官网、开放平台设计规范在本环境被网络策略拦截（见 依据/外部查证-20260919/02）。
- **交互约定**：第 4 节「移动端交互」是按飞书客户端常见做法写的约定，没有对官方页面核实，能上网的同事复核后再把状态改为已确认。
- **范围**：只动小程序（tokens `platforms.miniprogram`）。Web 端变量不变，是否也向飞书靠拢另议。

## 3｜组件库怎么接（ui-miniprogram 0.9.0）

- 卡片类（sb-summary-card、sb-section、sb-kpi-card、sb-metric-tile）默认无边框，白卡靠灰底区分；放在白底上时传 `bordered`。
- sb-status-tag、摘要卡范围标签改 4px 小圆角；sb-filter-bar、sb-date-picker 的快捷片改灰底无边框，选中浅蓝底主色字；sb-tabs 未选中用正文色。
- 表单件（sb-select、sb-date-picker、sb-amount-input、sb-textarea）新增 `layout="stacked"`（标签在上、带框控件）与 `plain`；sb-date-picker 新增 `mode="datetime"`；sb-sheet 按钮等分、底部安全区。
- TDesign 基础控件的主题由 bridge-tdesign 从 `--ui-*` 取值，变量换成飞书值后 t-* 自动跟随。

## 4｜页面规则（约定，未核实官方页面）

1. 白卡放在灰底上，不描边、不加阴影；阴影只给浮层。
2. 卡内分组用分隔线，不套小卡；分隔线从文字起点开始。
3. 文字三级：正文 ink，次要 14px secondary，说明 12px muted；字重 400、600。
4. 标签 4px 圆角、12px 字、浅底同色系深字。
5. 筛选片与分段：灰底无边框，选中浅蓝底主色字。
6. 下划线页签，选中主色 2px 下划线。
7. 表单：标签在上 14px 常规字重，控件白底细线 6px 圆角，必填星号在标签后，错误在控件下。控件高度飞书桌面端是 40px，小程序端取 44px（--ui-field-height，和点击底线一致，见第 5 节）。
8. 主按钮主色实底 44px 高 6px 圆角；次按钮白底细线；底部条按钮等分撑满。
9. 弹层一律底部弹出，上圆角、遮罩可关、安全区；选择器头部「取消 · 标题 · 确定」；居中弹窗只做确认。
10. 不用渐变、毛玻璃、装饰色块、英文眉题、emoji、整卡涂状态色。

## 5｜小程序使用体验（与飞书冲突时以此为准）

视觉学飞书，手感必须是微信小程序。依据：微信官方 WeUI 源码（Tencent/weui-wxss，官方事实）与《小程序设计指南》镜像原文（未能打开官网，见 依据/外部查证-20260919/04）。

| 项 | 规则 | 依据 |
|---|---|---|
| 导航 | 原生导航栏与原生 tabBar；不自绘导航与返回；右上胶囊区不放可点元素；完整详情用 navigateTo 进独立页，不做页面内全屏浮层 | 设计指南「导航栏直接继承于客户端」；页面栈生命周期 |
| 点击区域 | 可点元素高 ≥44px，列表行 ≥48px，相邻可点元素间距 ≥8px；**点击高度写 px 或 `var(--ui-touch-target)`，不写 88rpx**（rpx 随屏宽缩放，320 宽屏上 88rpx 只有 37.5px）；视觉小于 44px 的片、图标、小号按钮用伪元素 `::after` 以中线为准上下各 22px 扩区（`top/bottom: calc(50% - 22px)`），视觉尺寸不变 | 设计指南「7mm～9mm」；WeUI 按钮 48／40／32；2026-09-23 小程序 1.0.8 第三轮 320 宽复核 |
| 按下态 | 可点的行、卡片、按钮都有 hover-class（按下底色或透明度 0.7） | 小程序无悬停 |
| 字号 | 正文 16px，次要 14px，说明 12px，页面标题 20px；不小于 12px；字号写 px 不写 rpx（TDesign 的组合字体变量由桥接改成 px） | 设计指南常用字号 20／18／17／16／14／13 |
| 弹层 | 半屏从底部弹出，上圆角、高 ≤80%、可滚动、点遮罩关闭；选择器头部「取消 · 标题 · 确定」；不可逆操作用系统 wx.showModal | WeUI 半屏弹窗；设计指南 |
| 安全区 | 底部固定条与弹层底部：自身间距加安全区，constant() 与 env() 两行写，env 在后 | WeUI 源码写法 |
| 输入 | 数字 type=digit／number，搜索 confirm-type=search，fixed 区域的 textarea 加 fixed；能选就不让输入 | 小程序 input／textarea 属性 |
| 反馈 | Toast 只做轻量成功提示；失败写在页面或字段旁；加载用页面内骨架或状态面板，不整屏遮挡 | 设计指南「Toast 1.5 秒…不需要强调的操作提醒」「模态加载应谨慎使用」 |
| 页签 | 一页只一组标签分页栏 | 设计指南「一个页面也不应出现一组以上的标签分页栏」 |
| 滚动 | 页面整体滚动，避免嵌套纵向 scroll-view | 小程序手感 |

组件库（ui-miniprogram 0.9.0）已按此处理：sb-bottom-bar 与 sb-sheet 底部安全区两行写；摘要卡可点指标、描述列表可点单元、区块卡片右侧链接都有按下态，链接点击区域补足 44px。

第三轮复核（2026-09-23，375、360、320 三种宽度实测）后补上的：

- 分段（sb-segmented）项高 36px 加轨道上下 4px，轨道那 4px 也并进项的点击区；页签（sb-tabs）行高 42px 加 2px 下划线 = 44px，带按下态；筛选片、日期快捷片、指标条周期片、清除图标、状态面板的小号按钮都用伪元素扩到 44px。
- 表单控件高 44px（--ui-field-height 的小程序端值）。
- TDesign 的 `--td-font-body-*`、`--td-font-title-*`、`--td-font-mark-*` 在桥接里改成 px，320 宽屏上输入框文字不再缩到 13.7px。
- t-button 内部 `catch:tap` 吞掉原生点击：外面包一层 view 扩点击区时，**按钮本体与外层都要绑同一方法**（点按钮本体时外层收不到，点扩区时按钮收不到，不会重复触发）。
- 页面 app.wxss 若有 `button::after { border: 0; }`（去原生按钮边框），会经 TDesign 的 apply-shared 清掉描边按钮的线型，需补 `.t-button--outline::after { border-style: solid; }`。
- 字重只用 400 与 600（摘要卡标题与指标、指标卡、AI 标识、状态标签、时间轴标题都已改）。
