# 真实项目回流：小程序 1.0.8 改版

## 1｜页面反复手写的结构 → 新组件

## 3｜规范要补的（待评审，走变更单）

- 14 章补一条「手机页顶部用摘要卡，不用深色横幅」；登录页品牌区是唯一例外。
- 12 章 §2：小程序作战地图现为纵轴潜力、横轴关系，与 12 章相反；换 sb-battle-map 会破坏现有行为测试（象限放大、相邻点名单、触摸判定），等后端直接给象限、状态、金额档后再换。
- 11 章：「告警」「真实商机数据」「请确认…」这类说法与文案规范不符，页面本轮未改业务文案，需统一评审。
- A-01～A-04：拜访确认页字段三态仍是页面自绘，换 sb-ai-field 要为每个字段记录 AI 原值与确认状态，并改 16 项必填校验与草稿快照，建议单独立项。
- 原生 checkbox 的 color 与 wx.showModal 的 confirmColor 不认 var()，工程里集中在 utils/uiColors.js 一处写十六进制，变量改了要同步。

## 4｜工程接入方式（供其他小程序参考）

- 不开 npm：`frontend/scripts/vendor_ui.mjs` 做「构建 npm」的事，只拷页面用到的 sb-* 及其 TDesign 闭包到 `miniprogram/ui/`，ESM 转 CommonJS，tslib、dayjs 改相对路径，t-icon 字形表只留用到的。
- 页面引用写绝对路径 `/ui/sb/sb-xxx/index`。
- 去掉 `style: v2`（TDesign 要求）；app.wxss 里给页面原生 button 补回 v2 的字号与圆角（字重按飞书改 600）。注意 TDesign 组件是 `styleIsolation: apply-shared`，app.wxss 会进组件：`button::after { border: 0; }` 会清掉描边 t-button 的线型，要补 `.t-button--outline::after { border-style: solid; }`（第三轮发现，早先写的「t-button 有样式隔离不受影响」不对）。
- TDesign 的图标字体从 tdesign.gtimg.com 加载，内网环境需确认可达，否则图标显示为空。

## 5｜第三轮：原生与手绘控件换成熟组件（2026-09-23）

用户要求：视觉效果或体验不好的控件换最适配的成熟组件，视觉以飞书为核心参考，同时要符合小程序使用体验（冲突时小程序体验优先，见 16 章）。四组（A 首页与任务、B 客户、C 商机与拜访、D 看板与我的）先审计 138 处控件（100 处换、19 处只改样式、19 处保留），替换后经过三轮独立复核（375、360、320 三种宽度实测）。

替换：原生 picker 换 sb-select、sb-labeled-select（筛选片）、sb-date-picker（含 datetime）；14 处手绘底部弹层换 sb-sheet；原生 input、textarea 换 sb-input、sb-textarea、sb-amount-input；原生 checkbox-group 换 t-checkbox；手绘页签、分段换 sb-tabs、sb-segmented；「›」之类字符换 t-icon；列表行换 t-cell。

复核发现、已回流进组件库的：

| 页面里遇到的 | 组件库怎么接 |
|---|---|
| sb-input 框约 56px（t-input 自带 32rpx 内边距，t-input 是虚拟宿主，挂在它 class 上的变量在截图工具里不生效） | 组件在真实节点上清零；sb-textarea、sb-amount-input 同样处理 |
| 分段、筛选片、日期片高度写 rpx，320 宽屏点击高度 31～39px | 高度一律写 px，扩区伪元素以中线为准 `calc(50% - 22px)` |
| 页签点击高度约 37px；5 个页签在 375 宽放不下 | sb-tabs 行高 42px 加 2px 下划线；fit 按文字宽度分满，5 个及以上窄于 360px 退回横滑 |
| 页面记住密码明文状态、退后台要复位，组件内部状态接不上 | sb-input 受控 showPassword 与 visibility 事件 |
| 从成员下钻进任务页，再点已选中的「团队任务」要复位成员筛选 | sb-segmented emitSame |
| 默认排序、当前季度一直画成「已筛选」蓝底 | sb-labeled-select 默认值不算已选（defaultValue） |
| 弹层关闭动画期间还能点确定，重复保存 | sb-sheet 关闭中不再发 confirm；无按钮也留安全区 |
| 年份滚轮停在最早一年 | sb-select defaultValue |
| 未就绪按钮 45% 透明，白字落浅蓝底；禁用主按钮对比度不够 | inactive 与禁用都改中性浅灰底、弱化字 |
| 320 宽屏输入框文字 13.7px | 桥接把 TDesign 组合字体变量改成 px |
| 表单控件 40px 低于 44px 点击底线 | 小程序端 --ui-field-height 44px |
| t-button 内部 catch:tap，外包扩区后点按钮本体没反应（一次复核判为阻断） | 文档写明两层都绑；sb-state-panel 自己按此处理小号按钮 |
| 标题、指标、标签用了 500／700 | 统一 400／600 |

页面侧：可点元素的 88rpx 高度改成 `var(--ui-touch-target)`（50 处）；页面里为组件缺陷写的绕行规则在组件库修好后全部删除。
