# 规则映射表：样板每个部分引用了什么

用途：开发或测试对着样板的某个部件，查它依据哪条规则、是已确认还是建议、本轮验到哪一步。

状态只用五个词：**已确认** = Web V1 的 26 条规则原文；**建议** = X 章或本轮新增；**业务事实** = CLAUDE.md 与业务约束清单里的口径，不是设计规则；**已验证（本地）** = 自动验收通过（合成数据、模拟视口）；**未验证** = 无证据。编号说明：B-01～B-05 是规范的业务表达规则；「约-xx」是 `业务约束清单.md` 的编号，两者无关。
