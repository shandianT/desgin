# 真实项目回流：Web 候选版暴露的规范空白

规范是先于产品写的。第一个真实项目接上来，四页就露出了十几处规范没说、说得不够、或者说错了的地方。这份文档把它们记下来，分三类：要补规则的、要补组件的、要改文案表的。每条都写清在项目里的表现和建议的改法，评审通过后走变更单。

## 1｜规范没说的

| 项目里的表现 | 规范现状 | 建议 |
|---|---|---|
| 顶栏：面包屑「销售流程 / 客户」、右侧「＋ 新建」全局按钮、帮助、刷新 | 没有顶栏规则。T-01 到 T-05 只讲页面主体 | 新增 T-06 顶栏与全局操作：面包屑两级、一个全局新建、图标按钮必带 title；手机上顶栏收成标题加返回 |
| 左侧导航分组「销售流程」「经营复盘」，底部账号卡 | V-01 只定了颜色，没定结构 | 新增 T-07 导航结构：一级最多 7 项、可分组、当前项高亮用 `--ui-sidebar-active`、底部固定账号与退出 |
| 登录页：企业账号登录、示例体验两个入口 | 没有登录页规则 | 新增 T-08 登录：品牌名放这里、一个主入口、示例入口次级、隐私说明链接 |
| 标签页带数量「待处理 18」「已完成 4」 | C-05 没提标签页 | 补进 C-05：标签页数量用小号灰字，超过 99 显示 99+，当前页签用主色 |
| 优先级「高」「中」用红字、灰字 | 没有优先级规则。它不是红黄绿灰业务状态，B-01 不适用 | 补进 B-02：优先级只用文字加一个图标，高用 `--ui-danger` 字色，中低不上色 |
| 逾期时间「已逾期 16 小时」加原截止时间 | 11 章第 6 节只有相对时间和绝对时间 | 补进 11 章：逾期写「已逾期 N 小时／天」红字，下一行原截止时间灰字；今天到期写「今天 17:00」 |
| 客户 ACV、Tier-1 这类英文直接给用户看 | 11 章第 5 节有词表，没定英文缩写怎么办 | 补一条：对用户显示中文，ACV 写「年度合同额」，Tier 写「一级客户」，英文只留在代码和口径说明里 |
| 表格里空值显示「—」 | B-03 说缺失显示未登记 | 不改规则，改项目。列宽紧时允许「未登记」缩成「—」加悬停说明，写进 B-03 例外 |
| 示例模式横幅、角色切换 | 没有演示模式规则 | 新增 G-03 演示与真实：演示数据必须有一行标识但不用警告色，角色切换只在演示模式出现，正式登录不显示任何演示痕迹 |
| 桌面表格一屏只见 6 行 | T-02 没说密度 | 补进 T-02：列表页 900 高度下至少可见 8 行，行高 56 以内，分区标题不超过两行 |

## 2｜项目需要但组件库没有的

项目自己拼了这些，每个都拼得不一样。下一版组件库补上，按需要的页数排：

| 组件 | 项目里怎么拼的 | 建议 |
|---|---|---|
| 带标签的下拉筛选 `SbLabeledSelect` | antd Select 前面加一段灰字「象限」「计划」 | 做成一个组件，标签在框内左侧，值在右侧，清空回「全部」；小程序用 t-dropdown-menu |
| 指标条 `SbMetricStrip` | 三个 SbMetricTile 横排加「本年／历年」切换加口径提示 | 把周期切换和口径提示做进去，缺失显示未登记；手机两列 |
| 带数量的标签页 `SbTabs` | antd Tabs 手写数量 | 封装 antd Tabs，数量从数据来，超 99 显示 99+ |
| 顶栏 `SbTopBar` | 项目自己写 | 面包屑、全局新建、帮助、刷新，按 T-06 |
| 侧导航 `SbSideNav` | 项目自己写 | 分组、高亮、底部账号，按 T-07 |
| 表格 `SbTable` | 项目里问过有没有，没有 | 封装 antd Table：固定操作列、展开列、行高、空态接 SbStatePanel、分页接 SbPagination |
| 作战地图 `SbBattleMap` | 项目自己画 | 等 12 章定稿 |

## 4｜规范说错或不够的

- B-01 把状态标签写成「业务变化」，项目把任务状态「待接受」也塞进了标签。要在 B-02 里明说：对象状态用文字，红黄绿灰只给业务判断。这次评审已按此改了项目。
- C-04 筛选栏假设是筛选片，项目用的是下拉。两种都该允许，写清什么时候用片（选项少于 6）、什么时候用下拉。
- X-03 手机端只讲了列表进详情，没讲图表在手机怎么办。12 章 2.6 补了，X-03 要引用它。

## 5｜怎么处理

1. 第 1 节和第 4 节每条填一张变更单，一次评审过。
2. 第 2 节按顺序建组件：SbLabeledSelect、SbMetricStrip、SbTabs、SbTable 先做，四个都是三页以上要用的。
3. 第 3 节并进 11 章对照表。
4. 做完之后拿 Web 候选版再跑一遍，看 department-ui 里自己拼的东西能不能全换成组件。
