# 接入计划：小程序上 TDesign，Web 上 Ant Design

2026-09-20 定了三件事：Web 引入 React，主库 Ant Design 6 加 Ant Design X；小程序主库 tdesign-miniprogram；飞书感不作硬要求。这份文档把接下来要动的东西列清楚。第 1 节是小程序要授权的改动，第 2 节是 Web 样板的任务单。都没开始做。

## 1｜小程序接入：需要授权的改动

仓库 shandianT/xiaoshouguanli，目录 `frontend/miniprogram`。按顺序做，每步可以单独授权，做完一步就能回归一次。

| 序号 | 改动 | 涉及文件 | 风险 | 怎么回归 |
|---|---|---|---|---|
| 1 | 开 npm 支持，安装 tdesign-miniprogram 1.16.1，开发者工具里构建 npm 并勾选编译成 ES5 | `project.config.json`（nodeModules 改 true）、新增 `package.json`、`package-lock.json`、`miniprogram_npm/` | 包体积增加。可以只保留用到的组件目录，或开分包 | 编译通过，现有页面不变 |
| 2 | 删掉 `app.json` 里的 `"style": "v2"`，最低基础库设到 2.12.0 以上 | `app.json`、小程序后台设置 | 原生 button 与 input 的默认样式会变 | 逐页看原生按钮和输入框，记差异 |
| 3 | 引入变量与桥接：`app.wxss` 头两行 `@import "./design-tokens.wxss"; @import "./bridge-tdesign.wxss";`，两个文件从 desgin 仓库 `dist/` 复制 | `app.wxss`、新增两个 wxss | 无。此时还没有页面用变量，只是声明 | 编译通过 |
| 4 | `app.json` 的 window 与 tabBar 五项颜色按 `dist/miniprogram-app.tokens.json` 改。主色从 #1677FF 换成 #2863CD | `app.json` | 全局可见的颜色变化 | 首页截图前后对比 |
| 5 | 客户列表页改用 t-cell、t-search、t-dropdown-menu、t-tag、t-empty、t-loading，样式只写 `var(--ui-*)`。详情从页内浮层改成 `wx.navigateTo` 整页进入，返回保留搜索、筛选、滚动位置 | `pages/customers/` 下的 wxml、wxss、js、json | 这一页交互变化最大 | 页面验收单，按 03 章样板逐项对；真机看 px 与 rpx 观感、键盘上推、深色分支不误触发 |

| 7 | 在采用登记表登记：版本 1.16.1、采用范围、验证证据 | desgin 仓库 `采用登记表.md` | 无 | 无 |

先只做客户列表到详情这一页。其余 20 页按同样办法分批做，每批一个验收单。

前置要确认的：`"lazyCodeLoading": "requiredComponents"` 与 tdesign-miniprogram 的兼容性还没单独核实；`t-form` 的 rules 能不能表达拜访确认的 16 项加 4 项必填，要在拜访录入页做之前验一次。

## 2｜Web 样板任务单：任务工作台一页，岛屿式 React 加 Ant Design

按 1.0.0 模板 01 任务单填写。

| 项目 | 填写 |
|---|---|
| 任务名称／编号 | Web 岛屿式 React 样板，任务工作台右侧详情面板 |
| 产品、页面、终端 | SalesBuddy 电脑网页，任务工作台，电脑与收紧两档 |
| 规范版本与规则编号 | 规则 1.0.0；T-01、C-01、C-02、C-05、C-06、C-07；X-03；A-02、A-03、A-09 |
| 使用角色与业务对象 | 销售与主管；任务、关联的客户与拜访 |
| 现在的问题 | sales-web 没有前端框架，表格、表单校验、日期选择靠 vendor 拼；AI 界面没有组件可用 |
| 预期改善 | 一页用上 antd 的 Table、Form、DatePicker、Drawer 与 Ant Design X 的来源引用；主题只靠 `bridge-antd.theme.json`；量出体积与冲突，决定要不要扩大 |
| 正常流程：操作→结果 | 打开任务工作台，右侧面板由 React 渲染；点任务行，面板显示详情与 AI 即时总结，总结带 AI 标识与来源；改任务状态，保存后列表同步 |
| 关键异常：操作→结果 | 总结生成失败，面板显示原因与重试，列表条件不丢；无权限任务，面板不显示对象名；React 包加载失败，面板退回现有静态详情 |
| 数据、接口与权限依据 | 现有任务接口；权限按服务端返回；AI 总结走 Draft 类工具，不落库 |
| 复用的组件、页面模板 | antd 6.6 的 Table、Form、Drawer、Empty、Spin、message；@ant-design/x 2.9 的 Bubble 与 Sources 类组件；T-01 工作台模板 |
| 新增建议或例外 | 岛屿式挂载：Vite 加 React 18，在现有页面的一个容器 `createRoot`；弹层用 getPopupContainer 挂到面板内，避免和现有 z-index 冲突 |
| 产品／设计／开发／测试负责人 | 待填 |
| 交付环境、版本与时间 | 本地演示优先；antd 6.6.4、@ant-design/x 2.9.0、React 18 锁版；时间待定 |
| 验收结果在哪里记录 | 页面验收单，放在 desgin 仓库 `specs/salesbuddy/03-跨端样板-客户列表到详情/` 旁新建目录 |

样板要量三个数：首屏 JS 体积（gzip），与现有弹层的冲突个数，返回列表是否保留筛选与位置。三个数出来再定是否扩大到客户列表与拜访录入。
