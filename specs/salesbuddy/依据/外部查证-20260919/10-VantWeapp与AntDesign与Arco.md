# Vant Weapp／Ant Design（Web＋Mini）／Arco Design（Web＋Mobile）在销售智助场景的可用性查证（2026-09-19）

> 查证日期 2026-09-19。官网（semi.design、tdesign.tencent.com、weui.io、vant、ant.design、arco.design、webawesome.com 等）与 GitHub 网页／API 在本会话均被代理拦截；本文全部事实来自 raw.githubusercontent.com 的官方仓库源文件、registry.npmjs.org 元数据与实际下载的 npm 发布包。「官方事实」= 官方仓库文档或元数据原文；「仓库证据」= 读源码得到；「推论」= 由前两者推出；「未能核实」= 只在官网或不可达资源上有。由 AI 查证，待有网络的同事按来源复核。

查证结论：五个库的官网（vant-ui.github.io、ant.design、mini.ant.design、arco.design）全部被代理拦截（CONNECT 403），本次全部依据 GitHub 官方仓库源码（raw.githubusercontent.com）、npm registry 元数据与 npm 发布包（tarball）实物核实；凡只有官网才有的内容标「未能核实」。结论：①Web 端若采用 React，Ant Design 6（antd 6.6.4，2026-09-14 发布，MIT，周更）是首选：三层 Design Token＋v6 默认 CSS 变量，主色 colorPrimary 一行改成 #2863CD，dist 带 UMD；备选 Arco Design web-react 2.66.16（2026-07-14，MIT，主色以 `--primary-6`／`--arcoblue-6` 运行时 CSS 变量注入，配套 Design Lab 风格平台），Vue 3 项目则 Arco web-vue 2.58.0（2026-04-16，节奏偏慢）。②小程序端首选 Ant Design Mini 3.4.3（2025-12-12，MIT，npm `miniprogram` 字段直接指向微信编译产物 compiled/wechat/src，77 个目录约 70 个组件已适配微信，主题用 `page{--color-brand1…}` CSS 变量与 ConfigProvider themeVars，默认主色 #1677FF 与小程序现用一致，且自带 Form 校验），但需接受微信端「无作用域插槽」导致 Table／Grid／Collapse／IndexBar 插槽受限；备选 Vant Weapp 1.11.7——生态最大（18.4k star）、主题机制成熟（474 个 `--xxx` CSS 变量＋ConfigProvider theme-vars），但最近一次发版是 2024-10-14，距今 23 个月无版本，且没有 Form 组件、默认主色是绿色 #07c160，需要改的变量更多。③Arco Mobile（mobile-react 2.39.1，2026-06-03）只覆盖 H5／WebView，不覆盖微信小程序，npm 包 license 字段写 ISC 而仓库与包内 LICENSE 文件为 MIT，采用前需核对。Web 端排序（不含 Semi／TDesign）：Ant Design 6 ＞ Arco web-react ＞ Arco web-vue；小程序端排序：Ant Design Mini ＞ Vant Weapp（Arco 无小程序版）。

## findings

- **[未能核实] 官网全部不可达，本次证据来源为 GitHub 源码、npm 元数据与发布包实物**
  来源：curl 探测：https://vant-ui.github.io/vant-weapp/、https://ant.design/、https://mini.ant.design/、https://arco.design/ 均返回「CONNECT tunnel failed, response 403」；https://raw.githubusercontent.com 与 https://registry.npmjs.org 返回 200
  官网上的「组件总览」「主题编辑器」「Design Lab 风格配置平台」「微信已适配组件列表页」等只在站点渲染的内容无法直接查看，以下凡引用这些页面的结论均已改为读仓库 docs 源码或 npm 包内文件，并在对应条目注明。
- **[官方事实] Vant Weapp：仅覆盖微信小程序；最近发版 v1.11.7 为 2024-10-14，距今约 23 个月无新版本**
  来源：https://registry.npmjs.org/@vant/weapp（dist-tags.latest=1.11.7，time['1.11.7']=2024-10-14）；https://raw.githubusercontent.com/youzan/vant-weapp/dev/docs/markdown/changelog.md 首条即 v1.11.7 `2024-10-14`；dev 分支 package.json version 仍为 1.11.7
  README 明确：官方提供 Vue 2／Vue 3／微信小程序版本，React 版与支付宝小程序版由社区维护。仓库 pushed_at 2026-05-09（GitHub 搜索 API），说明 dev 分支仍有零星提交，但两年内没有任何发版；GitHub 18,449 star、3,459 fork、173 个 open issue、MIT（LICENSE 文件 Copyright 2016-present Youzan）。最低基础库 2.6.5。
- **[仓库证据] Vant Weapp 主题机制：CSS 变量（在 WXSS 里用 `var(--xxx, 默认值)` 读取的可覆盖变量）＋ ConfigProvider theme-vars；变量名没有 `--van-` 前缀**
  来源：https://raw.githubusercontent.com/youzan/vant-weapp/dev/docs/markdown/theme.md；https://raw.githubusercontent.com/youzan/vant-weapp/dev/packages/config-provider/README.md；npm 包 @vant/weapp@1.11.7 lib/button/index.wxss 与 lib/config-provider/index.wxml
  theme.md 给出三级定制：单组件 class 上写变量、容器节点上写变量、`page { --button-primary-background-color: … }` 全局生效；ConfigProvider 自 v1.7.0 起用 `theme-vars="{{ themeVars }}"`（驼峰键，如 buttonPrimaryBackgroundColor）经 wxs 映射成内联 CSS 变量。发布包实测：lib 目录共 474 个不同的 `var(--…)` 变量，编译产物形如 `background:var(--button-primary-background-color,#07c160)`，全部是 `--button-*`、`--tabbar-*` 这种组件前缀，唯一带 `--van-` 的是图标字体 `--van-icon-font-family`。任务描述中的「--van-* 变量」是 Vue 版 Vant 4 的命名，小程序版不是。Less 源变量表在 packages/common/style/var.less（567 个 `@` 变量，688 行）。
- **[仓库证据] Vant Weapp 默认主色是绿色 #07c160，蓝色 #1989fa 只用于 info／选中态，接入 #2863CD 需覆盖约 20 处变量**
  来源：https://raw.githubusercontent.com/youzan/vant-weapp/dev/packages/common/style/var.less 第 13、17、105～109、206、313～314、333、356、373、385、407、458、527、558、684 行
  `@button-primary-background-color: @green`，而 checkbox／radio／switch／slider／tabbar／tag／progress／nav-bar／notify／cascader 等的选中色用 `@blue`。没有一个「品牌主色」总变量可以一次改完，需要在 app.wxss 的 `page{}` 里把这两组变量逐个指向 #2863CD，与我们 tokens.json 的映射表要覆盖到组件级。
- **[仓库证据] Vant Weapp 共 72 个组件目录，覆盖 C-01／C-03／C-04／C-05／C-06／C-07，但没有 Form 组件，C-02「输入与校验」只能靠 Field 自行拼校验**
  来源：npm 包 @vant/weapp@1.11.7 解包后 lib/ 目录清单（72 项）
  对应关系：C-01 按钮 button（含 loading／disabled）；C-02 field、stepper、uploader、search（无 form／validator）；C-03 picker、datetime-picker、cascader、area、calendar、dropdown-menu、tree-select、checkbox、radio；C-04 dropdown-menu、search、tabs、tag；C-05 cell／cell-group、grid、index-bar、swipe-cell、sticky（无 table）；C-06 empty、loading、skeleton、toast、notify、dialog；C-07 popup、dialog、action-sheet、share-sheet、collapse、overlay。产品原则「销售不填复杂表单」减轻了没有 Form 的影响，但拜访确认 16 项必填校验仍需自写。
- **[官方事实] Ant Design Mini：定位是支付宝小程序库、同时兼容微信小程序与 uni-app；npm 的 `miniprogram` 字段直接指向微信编译产物**
  来源：https://raw.githubusercontent.com/ant-design/ant-design-mini/master/README.md（Multi Platform Support 段）；package.json `"miniprogram": "compiled/wechat/src"`、`files: ["es","less","compiled/wechat/src"]`；https://registry.npmjs.org/antd-mini
  README 原话：「Ant Design Mini supports use in both Alipay and WeChat mini programs, as well as running on uni-app」，并给出微信适配指南与 uni-app 指南链接。微信开发者工具「构建 npm」会按 `miniprogram` 字段取 compiled/wechat/src，页面里按 `"ant-button": "antd-mini/Button/index"` 引用（支付宝端是 `antd-mini/es/Button/index`）。最新 3.4.3 于 2025-12-12 发布，MIT（Copyright 2022 Ant Design Team），GitHub 551 star、152 fork、77 open issue，pushed_at 2026-06-01；2025 年 9～12 月发了 3.3.2→3.4.3 共 6 个版本。
- **[官方事实] Ant Design Mini 微信适配指南明确的限制：微信不支持插槽默认值与作用域插槽，因此 Grid／Collapse／IndexBar／Table／ThoughtChain／Slider／Voucher 的插槽能力在微信端受限**
  来源：https://raw.githubusercontent.com/ant-design/ant-design-mini/master/docs/guide/using-wechat.md「常见问题」；npm 包 antd-mini@3.4.3 compiled/wechat/src/*/index.md 中的「微信不支持」标注（Grid 143 行、Collapse 170 行、IndexBar 87 行、Table 185 行、ThoughtChain 70 行等）
  作用域插槽（父组件模板能拿到子组件传出的 item／index 的插槽）在微信小程序框架层面不存在，所以 Table 的单元格自定义、Grid／Collapse 的内容插槽在微信端不可用；NoticeBar 图标插槽需要额外设 slotIcon。指南还提醒：报 WXML 编译错误时要去掉 app.json 的 `componentFramework: glass-easel` 与 `lazyCodeLoading`。DatePicker 微信端只接受时间戳。「已适配组件列表」在官网由 wechat-component.tsx 渲染，仓库里找不到它 import 的 config/wechat.json（404），故以发布包实物为准：compiled/wechat/src 共 77 个目录，去掉 _util、mixins、style、_locale、ImageIcon、Mask、Pagination（文档代码里明确排除）后约 70 个组件。
- **[仓库证据] Ant Design Mini 主题机制：`:root, page{ --color-brand1: #1677ff … }` 全局 CSS 变量＋各组件 `--button-*` 变量＋ConfigProvider `themeVars`／`theme="dark"`，微信编译产物同样生效**
  来源：https://raw.githubusercontent.com/ant-design/ant-design-mini/master/docs/guide/customize-theme.md；https://raw.githubusercontent.com/ant-design/ant-design-mini/master/src/style/variables.less；npm 包 compiled/wechat/src/style/variables.wxss、style/themes/{color,theme-black,theme-mode}.wxss、ConfigProvider/index.wxml（`style="{{cssVarStyle}}"`）、Button/index.wxss（`padding: var(--button-padding, 24rpx)`）
  品牌色只有 `--color-brand1`／`--color-brand2`（默认 #1677FF，与小程序现用 #1677FF 一致），按钮再细分 `--button-primary-background-color` 等；内置浅色／深色两套并跟随 prefers-color-scheme。定制方式与 Vant Weapp 同构（单组件 class → 容器 → app 级 page{}），只是 themeVars 用的是短横线键 `'button-primary-background-color'`。尺寸单位是 rpx（微信小程序的响应式像素，750rpx = 屏宽），与我们 X-09「小程序按布局策略选 px/rpx」一致。ConfigProvider 在文档里仍标「实验性」。
- **[仓库证据] Ant Design Mini 微信版含 Form 家族（FormInput／FormPicker／FormDatePicker 等）并依赖 async-validator，可直接承接 C-02「输入与校验」**
  来源：npm 包 antd-mini@3.4.3 compiled/wechat/src/Form/ 子目录（FormInput、FormItem、FormPicker、FormDatePicker、FormCheckboxGroup、FormRadioGroup、FormRangePicker、FormRate、FormImageUpload…）；package.json dependencies 含 async-validator ^4.0.7

- **[官方事实] Ant Design（Web）：仅 React（peer react ≥18），antd 6.6.4 于 2026-09-14 发布，近 8 周每周一版；MIT；GitHub 99.5k star**
  来源：https://registry.npmjs.org/antd（versions 6.5.2～6.6.4 发布日期 2026-07-24～2026-09-14，共 942 个版本；6.0.0 发布 2025-11-21）；https://raw.githubusercontent.com/ant-design/ant-design/master/package.json；GitHub 搜索 API repo:ant-design/ant-design

- **[官方事实] antd 5／6 主题机制：Seed→Map→Alias 三层 Design Token，通过 `<ConfigProvider theme={{ token: { colorPrimary } , components, algorithm, cssVar, hashed, zeroRuntime }}>` 配置；v6 默认开启 CSS 变量**
  来源：https://raw.githubusercontent.com/ant-design/ant-design/master/docs/react/customize-theme.zh-CN.md（「基本概念」与「API › Theme」表）；https://raw.githubusercontent.com/ant-design/ant-design/master/docs/react/migration-v6.zh-CN.md 第 19、446 行；https://raw.githubusercontent.com/ant-design/ant-design/master/components/theme/themes/seed.ts
  Design Token（设计变量，主题的最小可调元素）默认值：colorPrimary #1677ff、borderRadius 6、controlHeight 32、fontSize 14、sizeUnit 4、sizeStep 4，与我们 V-02／V-03（正文 14px、控件圆角 6px、间距 4 的倍数）天然对齐，只有控件高度需从 32 调到 36／表单 40。cssVar 配置项 `prefix`（默认 ant）与 `key`；migration-v6 原话「v6 仅支持现代浏览器，并默认使用 CSS variables，因此不再支持 IE」。`zeroRuntime` 模式（6.0 起）可改为引入静态 `antd/dist/antd.css`，配合 @ant-design/static-style-extract 抽取。注意 ConfigProvider 对 message.xxx／Modal.xxx 静态方法不生效，要用 App 包裹或 useModal。
- **[仓库证据] antd 有 UMD：发布包 dist/ 含 antd.js、antd.min.js、antd-with-locales.min.js、antd.css、reset.css**
  来源：npm 包 antd@6.6.4 tarball 文件清单（package/dist/…）；https://raw.githubusercontent.com/ant-design/ant-design/master/docs/react/introduce.zh-CN.md 第 57～61 行「浏览器引入」
  UMD（Universal Module Definition，可用 `<script>` 标签直接引入、挂到全局变量 `antd` 的打包格式）存在，但仍要求页面先加载 React／ReactDOM；对现在「无框架、由小程序源码构建」的 sales-web 来说，UMD 只是过渡手段，真正用起来要引入 React。

- **[官方事实] Arco Design（Web）：React 版 @arco-design/web-react 2.66.16（2026-07-14，peer react ≥16，React 19 需引入 adapter）与 Vue 3 版 @arco-design/web-vue 2.58.0（2026-04-16）；两者均 MIT、均有 UMD**

- **[仓库证据] Arco 主题机制：Less 变量（`modifyVars: { 'arcoblue-6': '#…' }`）在构建期换色；运行时 CSS 变量 `--primary-6: var(--arcoblue-6)`、`--arcoblue-6: 22,93,255`（RGB 三元组）挂在 `body`，暗色挂在 `body[arco-theme='dark']`**
  来源：https://raw.githubusercontent.com/arco-design/arco-design/main/site/docs/theme.zh-CN.md；https://raw.githubusercontent.com/arco-design/arco-design/main/components/style/theme/default.less（`@arco-theme-tag: body`、`@arco-vars-prefix`）；components/style/theme/color/colors.less 第 108、315 行；npm 包 @arco-design/web-react@2.66.16 dist/css/arco.css（含 `--primary-6: var(--arcoblue-6)`、`rgb(var(--primary-6))`、`body[arco-theme='dark']`）

## recommendations

- Web 端先做一次技术决策：sales-web 现无组件框架，antd／Arco 的 UMD 都依赖 React 全局变量，实际落地都意味着引入 React（Vue 3 则只剩 Arco web-vue）。建议按「React ＋ antd 6」立项，用 `ConfigProvider theme={{ token:{ colorPrimary:'#2863CD', borderRadius:6, controlHeight:36 }, cssVar:{ prefix:'ui' } }}` 一次性对齐 V-01／V-03，再用 components 级 token 微调 Table／Form 高度（表单 40）；tom-select、flatpickr 由 Select／DatePicker 替换，echarts 保留。
- 小程序端建议选 Ant Design Mini 3.4.3，但采用前必须在微信开发者工具真机验证三件事：①拜访录入页用到的 Form＋FormPicker＋FormDatePicker 在微信端校验与回填是否完整；②客户列表若需 Table 单元格自定义，微信端不支持作用域插槽，需改用 List／Card 布局（与 C-05「不以卡片堆叠替代桌面列表」只约束桌面端不冲突）；③app.json 不能同时开 componentFramework: glass-easel 与 lazyCodeLoading，需核对现有 /home/user/xiaoshouguanli/frontend/miniprogram/app.json。
- 把「部门自己可直接调用的一套」做成三个产物而不是一个新组件库：tokens.json（已有）→ ①antd ThemeConfig JSON（Web），②`page{ --color-brand1:#2863CD; --button-primary-background-color:#2863CD; … }` 的 app.wxss 片段（antd-mini），③同名映射的 Vant Weapp 片段作为回退；三份都由 /home/user/desgin/specs/salesbuddy/02-设计变量与同步链路 的 build-tokens.mjs 生成，并纳入 lint-styles 的 baseline。这样满足「大厂成熟组件、最多微调、未来直接调用」。
