产品原则（业务事实）

原则以客户为核心，不以订单或商机为核心业务事实

客户下面挂商机、拜访、毛利、合同；一个客户可有多条商机。

来源：产品仓库 CLAUDE.md「必须遵守的产品原则」

原则销售不手工打分、不填复杂表单业务事实

语音口述拜访 → Agent 结构化 → 人工确认归档；象限、风险、画像由 Agent 依据已确认事实重算，不可手工拖动或改分。

来源：产品仓库 CLAUDE.md

原则四条不可破坏的原则业务事实

同一对象、同一事实、统一权限、关键动作可确认可追溯。

来源：产品仓库 CLAUDE.md

原则Agent 只生成草稿和洞察业务事实

写入正式业务表必须经人工确认；权限由服务端判定，数据库 RLS 兜底。

来源：产品仓库 CLAUDE.md
