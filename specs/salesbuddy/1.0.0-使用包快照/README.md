# 部门产品设计规范｜从这里开始

版本 1.0.0 · 2026-09-19

**解压完整文件夹，双击 `index.html`。** 它包含完整中文规范、三端建议、分工、变更和验收方法。浏览器阅读无需启动业务服务。

- 看实际效果：打开 `示例册/design-system/index.html`，或从阅读首页点击示例。
- 开始一项工作：复制 `模板/01-任务单.md`，填写页面、角色、规则编号与预期结果。
- 验收：填写 `模板/03-页面验收单.md`，记录实测结果和证据。
- 改规则：填写 `模板/02-规则变更单.md`，同步更新规则、示例、代码说明和验收项。
- 团队接入：由实际负责人维护 `模板/04-产品采用登记表.md`。

**已确认部分：SalesBuddy Web V1 的 26 条规则。** 跨端补充和部门协作方式为采用建议，相关负责人及其他产品范围待登记。文件完整不表示所有产品已完成实施。

转发时发送整个 ZIP，附上版本和日期。阅读稿和 ZIP 是分发快照；后续由规范维护人从同一维护源更新，避免产生多份“最终版”。手机系统若限制本地 HTML，需在允许的内部静态服务上打开后实测。

## 维护说明

`手册正文.md` 是本使用包说明与补充建议的维护源；第 05 章从上一级现行 Web 规范导入。`部门产品设计规范.md` 与 `index.html` 为生成结果，请先修改对应维护源再重新生成。

生成脚本在 `工具/生成使用包.mjs`。它只整理本包内容，不修改业务工程。使用时以 Node 执行，按本机安装路径设置 `MARKED_MODULE`，`WEB_SOURCE` 指向 sales-web 工程。规则、页面和资源检查完成后，再更新分发 ZIP 与校验清单。

第三方组件许可保留在 `示例册/assets/vendor/`；本包示例为合成数据，不连接业务接口或真实 AI。
