## 完成内容

1. **规则整理：** 设计原则、视觉基础、通用组件、五类页面模板、业务表达、验收维护六部分。每条有场景、要求、正反例、验收方法和编号。
2. **共享样式：** 新增 `design-tokens.css`，产品与示例共用。归并 `theme.css` 和 `visual-theme.css` 重复定义，保持已有变量名及实际生效色值；增加字体、间距、尺寸和语义色变量供逐步采用。
3. **交互示例：** 搜索、多选、清空、日期校验、弹窗、状态切换、AI 处理与失败恢复；首页红黄绿灰、商机双区筛选、客户／商机详情、拜访表单、季度图表。
4. **组件复用：** 下拉复用现有 SalesSelect／Tom Select 2.6.2；日期复用 SalesDatePicker／Flatpickr 4.6.13；图表复用 ECharts 6.1.0。未引入新依赖或改写第三方库。
5. **构建入口：** `npm run build` 输出 `dist/design-system/` 与共享变量；打包资源清单和独立构建测试已更新。源码与 README 提供维护入口，资产导航链接当前规范。

未新增业务 API、数据库表或权限规则。本轮未重新发布业务 ZIP、未部署外网。示例册模板不是现有 26 个业务页面全部达标的证明；旧页面偏差单列在验收清单。

## 修复的交互问题

- 原生说明弹窗在最后一个控件继续按 Tab 会经过页面外部焦点：示例弹窗补齐首尾焦点循环，Esc 关闭后回到原触发按钮。
- 共享下拉在首次自动聚焦前按 Esc，事件可能没有到达浮层：将活跃浮层的 Esc 处理放到文档捕获阶段，关闭时移除监听；新增立即取消的回归检查。
- 下拉先打开再异步填充选项，初始定位使用较小高度，内容填充后会短暂越出窗口：先准备选项再打开、定位。诊断逐帧记录到修复前短屏底部越界，单变量验证修复后无越界；正式测试逐帧检查窗口边界。

证据等级：本地构建＋隔离浏览器＋合成数据／原有本地 CRM 预览数据。没有验证真实身份认证、服务端组织权限、真实 AI 质检归档或跨端读回。

## 复现与维护

在 `sales-web` 工程目录运行：

```sh
npm run build
PLAYWRIGHT_MODULE='<本机 Playwright 模块路径>' node --test tests/design-system.browser.mjs tests/mature-components.browser.mjs tests/theme.browser.mjs tests/build.test.mjs
```

成熟组件中的 CRM 回归依赖本地 5196 服务与既有 `.runtime/crm-preview.json`；先用 `node scripts/start_crm_preview.mjs` 启动。其他检查自建临时本机服务。示例册自身不依赖 CRM 数据。更换电脑时将 `PLAYWRIGHT_MODULE` 指向当地 Playwright 安装路径。
