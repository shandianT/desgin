修复的交互问题

  • 原生说明弹窗在最后一个控件继续按 Tab 会经过页面外部焦点：示例弹窗补齐首尾焦点循环，Esc 关闭后回到原触发按钮。
  • 共享下拉在首次自动聚焦前按 Esc，事件可能没有到达浮层：将活跃浮层的 Esc 处理放到文档捕获阶段，关闭时移除监听；新增立即取消的回归检查。
  • 下拉先打开再异步填充选项，初始定位使用较小高度，内容填充后会短暂越出窗口：先准备选项再打开、定位。诊断逐帧记录到修复前短屏底部越界，单变量验证修复后无越界；正式测试逐帧检查窗口边界。

复现与维护

在 sales-web 工程目录运行：

npm run build
PLAYWRIGHT_MODULE='<本机 Playwright 模块路径>' node --test tests/design-system.browser.mjs tests/mature-components.browser.mjs tests/theme.browser.mjs tests/build.test.mjs

成熟组件中的 CRM 回归依赖本地 5196 服务与既有 .runtime/crm-preview.json；先用 node scripts/start_crm_preview.mjs 启动。其他检查自建临时本机服务。示例册自身不依赖 CRM 数据。更换电脑时将 PLAYWRIGHT_MODULE 指向当地 Playwright 安装路径。
