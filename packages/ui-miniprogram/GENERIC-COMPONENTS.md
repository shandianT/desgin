# 小程序通用组件迁移

当前包里的组件目录仍使用 `sb-*`，这是历史兼容名称。它们的通用语义已经可以被其他项目复用，但新项目应按本表接入，并等待对应的 `ds-*` 目录发布。

| 当前兼容组件 | 通用语义 | 新项目使用要求 |
|---|---|---|
| sb-status-tag | 状态标签 | 只传 tone、label、reason，不传 SalesBuddy 业务判断 |
| sb-state-panel | 加载、空、失败、无权限 | 页面提供 retry/clear 事件 |
| sb-filter-bar | 结果范围与筛选 | 页面维护真实筛选状态 |
| sb-list-row | 通用列表行 | 页面传入名称、摘要、状态和时间 |
| sb-field | 表单项与校验 | 页面传入校验结果，不由组件访问接口 |
| sb-tabs | 页签 | 页面决定路由和数据 |
| sb-pagination | 分页或加载更多 | 页面负责请求和错误恢复 |
| sb-ai-badge / sb-ai-field / sb-ai-progress | AI 结果状态 | 页面负责人工确认和正式写回 |

通用项目可以先使用现有 `sb-*` 目录，但必须在项目接入登记表里注明“兼容名称”。后续小程序包新增 `ds-*` 目录时，保持属性与事件语义不变。
